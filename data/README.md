# Data

## Titanic
Download `train.csv` from https://www.kaggle.com/c/titanic/data and save it here as `titanic.csv`.

Quick option (if you have the Kaggle CLI configured):
```bash
kaggle competitions download -c titanic -p .
unzip titanic.zip
mv train.csv titanic.csv
```
